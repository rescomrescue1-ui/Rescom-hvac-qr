RES-COM v23 — AUTH0 SETUP

The app integration is already built. Complete these steps in your Auth0 account:

1. Create an Auth0 tenant/account.
2. Applications > Create Application.
3. Name: Res-Com HVAC QR
4. Type: Single Page Application.
5. Copy Domain and Client ID into auth-config.js.
   DO NOT put a Client Secret in the browser app.

6. In the Auth0 application settings, add the EXACT Res-Com GitHub Pages URL:
   - Allowed Callback URLs
   - Allowed Logout URLs
   - Allowed Web Origins
   - Allowed Origins (CORS)

7. Authentication > Database:
   - Create/use a database connection.
   - Keep password authentication enabled.
   - Disable public sign-ups for production if only Res-Com employees should get accounts.
   - Configure a strong password policy.

8. Enable Universal Login.
9. Enable Identifier First authentication.
10. Enable Passkeys on the database connection.
    Auth0 requires passwords to remain enabled with passkeys.

11. Create the first employee user in Auth0.
12. Sign in to Res-Com with that user.
    If the Airtable Company Users table is empty, the first authenticated employee becomes the first Admin.
13. Admins can then create Company User profiles in Res-Com Settings.
    Each employee must also be created in Auth0 with the SAME email.

PASSWORD RESET
- Tap FORGOT PASSWORD in Res-Com.
- Auth0 sends a one-time password-reset email.

FACE ID
- Face ID is used by iOS to approve a passkey.
- Res-Com and Auth0 do not receive the user's Face ID biometric data.

IMPORTANT
Keep the same GitHub Pages URL so existing printed QR labels continue to work.
