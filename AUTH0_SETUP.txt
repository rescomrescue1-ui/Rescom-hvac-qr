RES-COM v25 — AUTH0 PHONE NUMBER LOGIN SETUP

The app is built to use the employee PHONE NUMBER as the company login identifier.

AUTH0 APPLICATION
1. Create/use the Res-Com HVAC QR Single Page Application.
2. Put the Auth0 Domain and Client ID in auth-config.js.
3. Keep the SAME GitHub Pages URL in:
   - Allowed Callback URLs
   - Allowed Logout URLs
   - Allowed Web Origins
   - Allowed Origins (CORS)

PHONE NUMBER LOGIN
4. Auth0 Dashboard > Authentication > Database > your Res-Com database connection.
5. Activate Flexible Identifiers / Attributes.
6. Turn ON: Use Phone Number as Identifier.
7. Set Allow Signup with Phone Number to REQUIRED.
8. Turn ON Verify Phone on Signup if you want each employee to prove ownership of the phone number.
9. Configure an Auth0 phone provider. Phone verification cannot work without a phone provider.
10. Use Identifier First authentication in Universal Login.

PASSWORDS / RESET
11. Keep password authentication enabled.
12. Configure the password policy.
13. Auth0 phone identifiers can be used for login and password reset when configured as an identifier.

FACE ID / PASSKEYS
14. Enable Passkeys on the database connection.
15. Universal Login + Identifier First are required for the standard Auth0 passkey flow.
16. Supported iPhones can approve a passkey using Face ID. Biometric data remains on the device.

CREATE COMPANY ACCOUNT
- The Res-Com CREATE COMPANY ACCOUNT button sends the user to Auth0 Universal Login with screen_hint=signup.
- Auth0 must allow signup on the database connection.
- For tighter company-only security, disable public signup and use an approved invitation/provisioning workflow instead.

RES-COM COMPANY USER MATCHING
- After Auth0 login, the app matches Auth0 phone_number to Airtable Company Users > Phone.
- If no Company User exists, v25 creates a Technician profile automatically.
- If the Company Users table is completely empty, the first authenticated user becomes Admin.

IMPORTANT
Keep the same GitHub Pages URL so existing printed QR labels continue to work.
