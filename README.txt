RES-COM HVAC QR APP — INSTALL / HOSTING

This package is a Progressive Web App (PWA) designed for iPhone and iPad.

IMPORTANT:
Do NOT open index.html directly from the iPad Files app. That is the problem with the old version.
The folder must be hosted at one permanent HTTPS web address.

Once hosted:
1. Open that HTTPS address in Safari on the iPad/iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open “Res-Com QR” from the Home Screen.
5. Tap Create Blank QR Label.
6. Print the QR and attach it to ONE piece of equipment.
7. Scan that QR.
8. Tap Set Up This Equipment and enter equipment information.
9. Later scans open that equipment record for service/tune-up/parts history.

DATA:
Equipment data is stored locally on each device.
Use Export Backup and Merge Backup to move/combine data between iPad and iPhone.
